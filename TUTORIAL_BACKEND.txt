=== CARA MENG-INSTALL APLIKASI PANITIA & PEDAGANG (TANPA FILE .APK) ===

Karena sistem ini telah menggunakan teknologi PWA (Progressive Web App), Anda tidak perlu repot mengirimkan file .APK yang rawan diblokir oleh Google Play Protect. 

Cukup ikuti langkah mudah ini:

UNTUK PENGGUNA ANDROID (Google Chrome):
1. Buka link web Panitia (misal: namawebanda.com/fgas/panitia.html) atau Pedagang di Google Chrome.
2. Di halaman login, Anda akan melihat tombol baru berwarna biru/oranye bertuliskan "Install App Panitia/UMKM".
3. Klik tombol tersebut, lalu pilih "Install" pada popup yang muncul.
4. Aplikasi akan otomatis ter-install di daftar aplikasi HP Anda dengan ikon khusus!
*Catatan: Jika tombol tidak muncul, klik tanda titik tiga di pojok kanan atas Chrome, lalu pilih "Tambahkan ke Layar Utama" (Add to Home screen).*

UNTUK PENGGUNA iPHONE/iOS (Safari):
1. Buka link web Panitia atau Pedagang di Safari.
2. Ketuk ikon "Share/Bagikan" (kotak dengan panah ke atas) di bagian bawah layar.
3. Gulir ke bawah dan ketuk "Tambahkan ke Layar Utama" (Add to Home Screen).
4. Ketuk "Tambah" di pojok kanan atas.
5. Selesai! Aplikasi FGAS sudah muncul di layar depan iPhone Anda dan akan berjalan full-screen tanpa menu browser.
