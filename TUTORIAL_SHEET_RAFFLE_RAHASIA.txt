=== PANDUAN SUPER SIMPLE: SHEET DOORPRIZE RAHASIA (V45) ===
Link Apps Script Anda sudah ditanam permanen di dalam fgas/raffle.html.

CARA PAKAI DI GOOGLE SHEETS RAHASIA:
Cukup ketik di Kolom A (bisa mulai dari A1 atau A2):
- Nama Lengkap (misal: BUDI SANTOSO), ATAU
- Nomor HP (misal: 08123456789), ATAU
- ID Tiket (misal: FGAS-931466)

KODE APPS SCRIPT (Tempel di Ekstensi > Apps Script pada Sheet Rahasia Anda):

// --- COPY MULAI DARI SINI ---
function doGet(e) {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
  const rows = sheet.getDataRange().getValues();
  const items = [];
  const skipHeaders = ['pemenang', 'nama', 'target_pemenang', 'nomor', 'hp', 'no'];
  for (let i = 0; i < rows.length; i++) {
    const val = String(rows[i][0] || '').trim();
    const status = String(rows[i][1] || '').trim().toLowerCase();
    if (val !== '' && !skipHeaders.includes(val.toLowerCase()) && status !== 'selesai') {
      items.push({ Pemenang: val, Status: status });
    }
  }
  return ContentService.createTextOutput(JSON.stringify({ status: "success", items: items }))
    .setMimeType(ContentService.MimeType.JSON);
}
// --- AKHIR COPY ---
