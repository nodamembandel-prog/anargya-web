=== PANDUAN SPREADSHEET RAHASIA KONTROL DOORPRIZE VJ ===
File Google Sheets ini 100% TERPISAH dan TERSEMBUNYI dari Spreadsheet Database Utama.

LANGKAH 1: BUAT SPREADSHEET BARU
1. Buka https://sheets.new (buat Google Sheet baru di akun Google Anda).
2. Beri nama bebas, misal: "Kontrol Doorprize Rahasia FGAS 2026".
3. Di Sheet1 baris pertama (Header), isi kolom A sampai E persis seperti ini:
   A1: No
   B1: Hadiah
   C1: Sponsor
   D1: Target_Pemenang
   E1: Status

   Contoh isi baris ke-2:
   A2: 1 | B2: Sepeda Listrik | C2: Bank Jateng | D2: BUDI SANTOSO (FGAS-123456) | E2: Aktif
   (Kosongkan kolom D jika ingin sistem mengacak pengunjung secara otomatis!)

LANGKAH 2: PASANG APPS SCRIPT
1. Klik menu "Ekstensi" > "Apps Script".
2. Hapus semua kode bawaan, lalu tempel kode di bawah ini:

// --- COPY MULAI DARI SINI ---
const VJ_TOKEN = 'RAHASIA_VJ_2026';

function doGet(e) {
  if (!e || !e.parameter || e.parameter.token !== VJ_TOKEN) {
    return ContentService.createTextOutput(JSON.stringify({ status: "error", message: "Access Denied" }))
      .setMimeType(ContentService.MimeType.JSON);
  }
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
  const rows = sheet.getDataRange().getValues();
  const items = [];
  if (rows.length > 1) {
    const headers = rows[0];
    for (let i = 1; i < rows.length; i++) {
      let obj = {};
      for (let j = 0; j < headers.length; j++) {
        obj[String(headers[j]).trim()] = rows[i][j];
      }
      if (obj.Hadiah || obj.Target_Pemenang) items.push(obj);
    }
  }
  return ContentService.createTextOutput(JSON.stringify({ status: "success", items: items }))
    .setMimeType(ContentService.MimeType.JSON);
}
// --- AKHIR COPY ---

LANGKAH 3: DEPLOY SEBAGAI WEB APP
1. Klik "Terapkan" (Deploy) > "Deployment baru" (New deployment).
2. Pilih jenis: "Aplikasi Web" (Web app).
3. Yang memiliki akses: pilih "Siapa saja" (Anyone).
4. Klik "Terapkan", lalu COPY link URL Web App (berakhiran /exec).

LANGKAH 4: HUBUNGKAN KE HALAMAN VJ
1. Buka https://anargya.pro/fgas/vj.html
2. Arahkan mouse ke bawah untuk membuka VJ Control Panel.
3. Di panel ungu "2. Remote Sheet Rahasia", tempel URL Web App tersebut lalu klik "Simpan".
4. Daftar hadiah & target pemenang dari Spreadsheet Rahasia akan langsung muncul! Klik "PAKAI" lalu klik "MULAI (15 DTK)".
